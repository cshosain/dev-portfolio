## 💡 How to Use

1. **Clone the repository:**
   ```bash
   git clone https://github.com/cshosain/hailee-portfolio-website-main.git
   ```
2. **Open `index.html` in your browser**  
   No build step required—everything is static!

3. **To deploy:**
   - Use [GitHub Pages](https://pages.github.com/) for free static hosting.
   - Or deploy to any static hosting provider (Vercel, Netlify, Render, etc.).
